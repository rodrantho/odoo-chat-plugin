Conectar o desconectar

Pedí revisar la conexión y abrí el enlace HTTPS. El formulario guarda o reemplaza tu conexión cifrada por identidad de ChatGPT en el servicio del complemento. Desconectar mi cuenta elimina la conexión activa del servicio; para revocar la clave también tenés que hacerlo en Odoo.

Desinstalar el complemento no revoca la clave en Odoo. Cada persona debe autenticarse con su propia cuenta y configurar su conexión Odoo. Las claves no se guardan literalmente dentro de ChatGPT.

Se admite Odoo 17 con API externa y HTTPS público. No hay plazos de atención ni disponibilidad garantizados. Las pruebas automatizadas usan datos ficticios; la compatibilidad con módulos personalizados y la entrega real de correo requieren verificación en cada entorno.
