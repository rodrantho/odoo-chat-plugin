Conectar o desconectar

La pantalla de configuración permite guardar y reemplazar tu conexión personal. Desconectar elimina la conexión guardada en el servicio; para revocar la clave también tenés que hacerlo en Odoo.

La primera versión admite Odoo 17 con API externa y HTTPS público. No hay plazos de atención ni disponibilidad garantizados anunciados para esta versión en preparación.
