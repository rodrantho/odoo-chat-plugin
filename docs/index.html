Cómo instalar

Consultá

Buscá contactos, leé el historial de tickets y consultá registros, totales y grupos de los módulos a los que tengas acceso.

Aprobá los mensajes

Revisá texto, destinatarios, visibilidad y adjuntos antes de publicar respuestas o notas. Si corresponde cerrar un ticket, el asistente lo propone para tu aprobación separada.

Configurá tu cuenta

Ingresá URL, base de datos, usuario y clave API en el formulario HTTPS del servicio. Se guarda cifrada por tu identidad autenticada de ChatGPT; nunca se pide por chat.

Instalar y conectar

  1. Usá un cliente compatible con complementos remotos y conectá tu cuenta.
  2. Agregá el repositorio de GitHub como marketplace e instalá Odoo desde Odoo · Anthony Rodríguez.
  3. Abrí un chat nuevo y pedí revisar tu conexión de Odoo.
  4. Abrí el enlace HTTPS de configuración y completá los cuatro datos de tu instancia. Comprobá y guardá.

Esta versión requiere Odoo 17 con HTTPS público y API externa habilitada. La instalación desde GitHub no publica el complemento en el catálogo oficial de OpenAI. El uso entre dispositivos depende del soporte del cliente para esa conexión remota; no requiere una PC propia encendida.

Dónde quedan los datos

El servicio conecta con tu Odoo y guarda la conexión cifrada, separada por la identidad de ChatGPT verificada por Sites. No copia conexiones entre usuarios. El operador administra el servicio y el secreto de cifrado.

Las claves no quedan literalmente dentro de la cuenta de ChatGPT: residen en el servicio del complemento. La conexión alojada puede utilizarse desde clientes compatibles con la misma identidad autenticada, sin depender del perfil Windows.

Los datos consultados que aparecen en el chat sí son procesados normalmente por ChatGPT/Codex y Odoo. Publicar una respuesta no confirma que el correo haya sido recibido.

Investigación y seguimiento

El asistente consulta lo necesario y prepara el trabajo sin pedir permiso por cada lectura. Puede sugerir revisar un ticket periódicamente; activarlo requiere tu aceptación y un planificador compatible con estado persistente y notificaciones. El complemento no incluye un temporizador propio.

Sin novedades, el control compacto evita devolver cuerpos e historial. Las respuestas, notas y cierres siguen sujetos a aprobación. Las tareas del asistente pueden consumir tokens; no se promete coste cero.
