Cómo instalar

Consultá

Buscá contactos, leé el historial de tickets y consultá registros, totales y grupos de los módulos a los que tengas acceso.

Aprobá los mensajes

Revisá texto, destinatarios, visibilidad y adjuntos antes de publicar respuestas o notas. Si corresponde cerrar un ticket, el asistente lo propone para tu aprobación separada.

Configurá tu cuenta

Ingresá URL, base de datos, usuario y clave API en un formulario de tu PC. Windows protege la conexión para tu perfil. La clave no se envía al chat.

Instalar y conectar

  1. Instalá Node.js 24 o posterior y usá un cliente de escritorio compatible con complementos locales.
  2. Agregá el repositorio de GitHub como marketplace e instalá Odoo desde Odoo · Anthony Rodríguez.
  3. Abrí un chat nuevo y pedí revisar tu conexión local de Odoo.
  4. Abrí el enlace 127.0.0.1 y completá los cuatro datos de tu instancia. Comprobá y guardá.

Esta versión requiere Odoo 17 con HTTPS público y API externa habilitada. La instalación desde GitHub no publica el complemento en el catálogo oficial de OpenAI. Esta distribución local no funciona en el navegador web ni en el móvil.

Dónde quedan los datos

El proceso local conecta directamente con tu Odoo. La conexión se guarda fuera del repositorio, cifrada con Windows DPAPI para tu perfil. No usa el servicio alojado de desarrollo ni una base compartida de claves.

La cuenta de ChatGPT no guarda ni sincroniza automáticamente esa configuración. Si varias personas usan el mismo perfil Windows, comparten su conexión local aunque cambien de cuenta ChatGPT. Usá perfiles Windows distintos para separarlas.

Los datos consultados que aparecen en el chat sí son procesados normalmente por ChatGPT/Codex y Odoo. Publicar una respuesta no confirma que el correo haya sido recibido.
