Tu Odoo.
En el chat.

Consultá tus datos y pedí cambios usando tu propia cuenta de Odoo. Una integración independiente creada por Anthony Rodríguez.

Gratuito · código bajo licencia MIT · Odoo 17

Consultá

Buscá contactos, leé registros, contá resultados y agrupá datos de los módulos a los que tengas acceso.

Cambiá, a pedido

Creá o editá registros cuando lo solicites expresamente. Se aplican tus permisos y las automatizaciones de Odoo.

Tu conexión

Configurá URL, base de datos, usuario y clave API. La conexión se guarda cifrada y separada de otros usuarios.

Cómo se conecta

  1. Iniciá sesión con ChatGPT.
  2. Completá los cuatro datos de tu instancia de Odoo 17.
  3. Comprobá y guardá la conexión.
  4. Usá el complemento desde el chat. Podés desconectarte desde la configuración.

Esta primera versión requiere HTTPS público y API externa habilitada. No ofrece eliminación de registros ni administración de credenciales.
