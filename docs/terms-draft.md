# Condiciones de uso — borrador para revisión del creador

Servicio gratuito de Anthony Rodríguez para conectar una instancia propia de Odoo 17. Integración independiente, no oficial de Odoo.

La persona configura una cuenta de Odoo que esté autorizada a usar y es responsable de sus permisos y claves. El conector respeta los permisos que Odoo aplica a esa cuenta. Las operaciones de creación/edición se ofrecen para pedidos explícitos de la persona y pueden activar automatizaciones de Odoo.

El conector no ofrece eliminación de registros, envío de métodos arbitrarios ni administración de credenciales/permisos. Requiere una API externa disponible y un servidor HTTPS público. No se garantiza compatibilidad con versiones distintas de Odoo 17.

Pendiente de decidir por el creador: condiciones de disponibilidad y soporte, usos permitidos/prohibidos, suspensión/terminación, responsabilidad por operaciones solicitadas, cambios, ley aplicable y procedimiento de reclamaciones. No se han aceptado ni publicado compromisos legales en nombre del creador.
